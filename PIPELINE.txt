# Audio Dataset Pipeline

---

## 1. Gemini Diarization (`infer.py`)
*Diarize và transcribe audio qua Gemini API.*

**Input:**
- `--audio-file`: File audio (hoặc `--youtube-url` tải trên trình duyệt)
- `--api-key`: Gemini API key (từ Env hoặc truyền vào)

**Output:**
- File `*.txt` với định dạng: `HH:MM:SS - HH:MM:SS | file_id | speaker_name | gender | transcript`
- Usage Tokens được in ra màn hình console.

**Tham số (Hyperparameters):**
- `--model`: (Mặc định: `gemini-3-flash-preview`)
- `--segment-seconds`: Số giây chia nhỏ mỗi đoạn để gửi API (Mặc định: `600s`)
- `--time-format`: Định dạng thời gian `hms` (HH:MM:SS) hoặc `seconds` (Mặc định: `hms`)

---

## 2. Audio-only Dataset (`run_pipeline.py`)
*Diarize bằng Pyannote, map speaker từ text, và đóng gói Dataset.*

**Input:**
- `--audio-dir`: Thư mục lưu file audio `/outputs`
- `--audio-files`: Danh sách cắt list file cụ thể (tùy chọn) 
- `--label-csv`: Metadata của speaker
- `--hf-token`: HuggingFace Token (sử dụng model Pyannote)

**Output:** 
(Lưu trong thư mục `--output-dir`):
- `wavs/`: Các file wav chia nhỏ mono 16kHz
- `metadata.csv`: Tổng hợp toàn bộ timestamps, audio files và infor speaker
- `speaker_name_mapping.csv`: Mapped Speaker names 
- `hf_dataset/`: Định dạng HuggingFace Dataset

**Tham số Diarization:**
- `--merge-gap`: Nối ghép segment nếu khoảng cách ≤ 2.0s
- `--min-segment-duration`: Loại bỏ segment < 2.5s
- `--max-segment-duration`: Tách segment nếu > 20s
- `--min-overlap`: Ngưỡng ghép nối speaker từ transcript (chuẩn 0.7)

## 3. Legacy Dataset (`run_pipeline.py --input-json`)
*Tạo dataset từ file JSON đã được đánh dấu sẵn.*

**Input:**
- `--input-json`: File config JSON chứa thông tin audio, segments cũ/mới và transcript text.
- `--label-csv`: Metadata của speaker

**Output:** 
- Giống mục **2. Audio-only Dataset** (`wavs`, `metadata.csv`, `hf_dataset`).

---

## 4. Add Speaker Info (`add_speaker_info.py`)
*Tool cập nhật và fill speaker name vào file cấu hình JSON của Legacy Mode.*

**Input:**
- `--csv`: File CSV metadata
- `--config`: File JSON cấu hình hiện tại

**Output:**
- File Config JSON sau khi bổ sung trường `speaker_id`, `speaker_name`, `gender`, `region`...
